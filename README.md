# Manya Maheshwari — Portfolio

A responsive, editorial-style personal portfolio for digital marketing, brand strategy, content and analytics.

## Files

- `index.html` — page structure and portfolio copy
- `styles.css` — responsive layout and visual styling
- `script.js` — mobile navigation and interactive case-study panels

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Deploy with Vercel

1. Sign in to [Vercel](https://vercel.com/).
2. Choose **Add New → Project** and import `maheshwarimanya472-ux/Portfolio` from GitHub.
3. For a static HTML site, leave the framework preset as **Other** and leave the build command and output directory empty.
4. Click **Deploy**. Vercel will redeploy when new commits are pushed to the connected branch.

## Before sharing publicly

- Replace the generic LinkedIn URL in `index.html` with your profile URL.
- Add a verified LinkedIn profile link and any portfolio pieces you want to publish.
- Review all copy, tools and experience details for accuracy.
- Add real brand examples, links and evidence to the independent case studies as the research is completed.

The three brand case studies are presented as independent strategic frameworks, not commissioned work or completed brand audits.
